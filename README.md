# 루브릭 메이커

한국 초·중등 교사가 최소한의 수업 정보를 입력하면 문항 초안과 서·논술형 분석적 루브릭을 자동으로 구성하는 정적 웹앱입니다.

## 주요 기능

- 교과·학년·성취기준·평가 내용·문항 수의 간단한 입력
- 성취기준과 평가 내용을 반영한 문항 초안 자동 구성
- 문항별 채점요소, 척도, 수행 특성, 유의점 자동 구성
- 브라우저 자동 저장, 예시 입력, JSON 저장, 인쇄/PDF 출력
- 별도 서버와 API 없이 브라우저에서 실행

## 실행

`index.html`을 브라우저로 열거나 정적 파일 서버를 사용합니다.

```bash
python3 -m http.server 8080
```

그다음 `http://localhost:8080`에 접속합니다.

## 설계 근거

예시 서·논술형 평가자료의 `성취기준 → 평가 내용 → 문항별 채점요소 → 척도별 수행 특성 → 유의점` 흐름만 남겼습니다. 평가 설계 전체 문서가 아니라 실제 채점에 필요한 루브릭을 빠르게 만드는 데 집중합니다. 생성 결과는 초안이며 학교 상황과 학생 수준에 맞게 교사가 최종 검토해야 합니다.
