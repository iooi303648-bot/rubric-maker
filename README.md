# 루브릭 메이커

한국 초·중등 교사가 성취기준과 문항 정보를 입력해 서·논술형 분석적 루브릭을 만드는 정적 웹앱입니다.

## 주요 기능

- 수업 맥락 → 평가 근거 → 문항 설계 → 검토의 4단계 입력
- 문항별 채점요소, 척도, 수행 특성, 유의점 자동 구성
- 총점에 따른 성취 수준 구간 자동 제안
- 브라우저 자동 저장, 예시 입력, JSON 저장, 인쇄/PDF 출력
- 별도 서버와 API 없이 브라우저에서 실행

## 실행

`index.html`을 브라우저로 열거나 정적 파일 서버를 사용합니다.

```bash
python3 -m http.server 8080
```

그다음 `http://localhost:8080`에 접속합니다.

## 설계 근거

예시 서·논술형 평가자료의 `성취기준 → 평가 내용 → 문항별 채점요소 → 척도별 수행 특성 → 유의점 → 평가 결과 구간` 흐름을 웹 입력·출력 구조로 옮겼습니다. 생성 결과는 초안이며, 점수 구간과 수행 특성은 학교 상황과 학생 수준에 맞게 교사가 최종 검토해야 합니다.
